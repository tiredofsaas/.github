## Projects

| Repository | What it is |
|---|---|
| [revu-mcp](https://github.com/tiredofsaas/revu-mcp) | Model Context Protocol server for working with PDF drawings and markups on a Windows machine with Bluebeam Revu 21 installed. 28 tools. Falls back to open-source PDF libraries when the installed licence tier does not allow headless scripting. |

## Ground rules

- Nothing here bypasses, patches or works around any vendor licence or entitlement check. Where a vendor feature is not licensed, the tool does the job another way with open-source libraries, or tells you it cannot.
- No vendor software, documentation or data files are redistributed.
- Product names are used only to say what the tool works with. These projects are not affiliated with or endorsed by any vendor.
- Issues and pull requests are welcome. There is no support commitment, no roadmap and no SLA.
